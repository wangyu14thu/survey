### 4. 动画效果

#### 新增动画列表
| 动画名称 | 效果 | 应用位置 |
|---------|------|---------|
| headerGlow | 头部光晕脉冲 | 顶部背景 |
| bounce | 上下弹跳 | 背包图标 |
| float | 漂浮移动 | 云朵装饰 |
| twinkle | 闪烁缩放 | 星星装饰 |
| roadFlow | 流动效果 | 路线圆点 |
| cardPulse | 卡片脉冲 | 进行中卡片 |
| glowPulse | 光晕脉冲 | 站点光晕 |
| iconRotate | 轻微旋转 | 进行中图标 |
| badgePop | 弹出效果 | 完成徽章 |
| tapHintFloat | 浮动提示 | 点击按钮 |
| tipBlink | 闪烁效果 | 提示图标 |

### 5. 颜色方案

#### 背景渐变
```css
background: linear-gradient(180deg, 
  #FFF5F5 0%,   /* 浅粉色 */
  #FFF8E1 50%,  /* 浅黄色 */
  #E3F2FD 100%  /* 浅蓝色 */
);
```

#### 状态颜色
| 状态 | 主色 | 辅助色 | 应用 |
|-----|------|--------|-----|
| active | #FF8C42 | #FFD700 | 进行中 |
| completed | #4CAF50 | #8BC34A | 已完成 |
| locked | #BDBDBD | #9E9E9E | 未解锁 |
